How Sax Roll works

What it does: turns sheet music of any song into a scrolling fingering guide — colored bars roll toward a fixed "now" line, showing exactly which keys to press, timed to the actual music. Works from any sheet music you've got — a PDF, a scan, or an already-digital file — not just a narrow set of pre-loaded songs.

Getting started: tap "Choose File" and pick a MusicXML file (or try one of the demo buttons first with no file needed), then hit Play. Only have a PDF or a scan? See "Where do I get a MusicXML file?" on the Load a song card — it walks through converting any sheet music into a file this can read. Follow the bars as they reach the now line — each colored lane is a specific key on the horn (see the Key guide for exactly which).

Tempo: the bpm slider and number box on the Play card let you slow a song down to isolate hard passages, or speed it up — from 1 to 250 bpm, independent of what the file's original tempo was. Slowing down also spaces the bars out more, making fast passages easier to read.

Difficulty & Simplify: every song gets an automatic difficulty estimate (Beginner through Expert) based on how fast, wide-ranging, and technically demanding it actually is. If a song's too hard as written, the Simplify dropdown has 5 levels — Light through Crazy Easy — that reduce note density and swap a few of the hardest fingerings for easier nearby ones, so any song can be made approachable at any skill level.

Instrument & Octave: switch between Alto, Soprano, Tenor, and Baritone to get correct fingerings and concert pitch for your actual horn. The Octave control shifts a song up or down a full octave if it's written awkwardly high or low — it'll refuse the shift if any note would fall outside the playable range, rather than guessing.

Trills: notes marked as trills show a zigzag line instead of a solid bar in whichever key needs to rapidly alternate — the sound alternates too, not just the visual.

Fullscreen: the ⛶ Fullscreen button expands the highway to fill your whole screen with on-screen play/tempo controls, useful for practicing at a distance from your device.

Saved songs: once you've loaded a song from a file, save it under a name so you don't need to re-upload it next time — stored on this device, in this browser.

Recommended way to learn a new song: Simplify and Tempo are meant to be used together, not separately — this is the method that actually works, rather than just struggling through a hard song at full speed from the start.

  1. Load the song and set Simplify to the highest level, Crazy Easy.
  2. Start the tempo slider slow — slow enough to play through comfortably — and gradually speed it up over as many sessions as it takes, until you can play it at the song's full tempo at this simplification level.
  3. Drop Simplify down one level (Crazy Easy → Very Strong). This brings back a bit more of the real song.
  4. Repeat the same pattern at the new level: start slow, speed back up to full tempo.
  5. Keep working down through the levels the same way — Very Strong → Strong → Medium → Light → Off — one level at a time, always starting slow and building back up to full tempo before moving on.
  6. Once you're comfortable at full tempo with Simplify set to Off, you're playing the actual song, at its real speed, having built up to it instead of fighting through it from day one.
Clarinet Roll

You're now in Clarinet Roll — Bb clarinet, chalumeau and clarion registers (E3 to C6, 33 notes), fingerings and transposition verified against multiple independent sources.

What's different from sax: the top lane is the register key (labeled "Reg") rather than an octave key — clarinet jumps a twelfth, not an octave, when you press it. L1-L3 and R1-R3 are the same left/right-hand finger-hole idea as sax. Extra keys (pinky keys, throat-tone keys) appear below as needed, same as sax's aux rows.

One honest note: the key guide diagram is a clean schematic rather than traced from an actual photo the way the sax one was — the shape and key positions are accurate, it just doesn't carry that same photo-traced precision. Everything else — fingerings, transposition, difficulty rating, audio, the tuner — is fully verified.

⚠ This only reads MusicXML files (.xml, .musicxml, or .mxl) — not PDFs, images, or scanned sheet music. A PDF's notes are pixels, not data, so there's nothing here to parse directly.

Where do I get a MusicXML file?

If it's already digital sheet music — from MuseScore, Finale, Sibelius, Dorico, Flat.io, or Soundslice, just export/download it as MusicXML from whichever of those made it.

Free scores: musescore.com (huge community library, most scores downloadable as MusicXML), musopen.org (public-domain classical), and flat.io all offer direct MusicXML downloads.

If all you have is a PDF (bought sheet music, a scan, IMSLP, etc.), convert it first:

  1. Download MuseScore 4 (free) from musescore.org — desktop app, not the mobile app or website.
  2. Open it, then File → Import PDF... (a separate option from regular "Open" — this is the one that reads the PDF into notes).
  3. Wait for it to process. It'll open as an actual editable score, not a picture.
  4. Skim it against the original PDF and fix any notes/rhythms it misread — automatic reading isn't perfect, especially in busy measures.
  5. File → Export..., set the format dropdown to MusicXML (not PDF, which is the default), and save.
  6. Upload that exported file here.

This whole process is for your own copy of music you already own or have rights to use — same as using a fingering chart alongside any sheet music.

About the fingerings

Every fingering in this app — all 33 notes, low Bb3 through high F#6 — has been checked against multiple independent, authoritative fingering references, with full agreement across sources. The one exception is written high F#6, which needs an optional key that not every alto has; that note is flagged when it comes up, and the fingering shown assumes your horn has it. Where a note has other valid alternate fingerings (which is common on saxophone), this app always shows the one standard choice, not every option.

Built for practicing, not performing — this isn't a substitute for a teacher's ear. Have fun learning the song.
